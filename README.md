# Elegant Fractures | 우아한 균열

An interactive, phone-inspired companion website for the fictional 2027 Korean romance drama **《우아한 균열》**.

## Planned experience

- A smartphone-style home screen
- Notes with separate folders for **재율과의 기록** and **명가 기록**
- Calendar, contacts, calls, messages, browser and gallery
- Spoiler-aware character introductions and a five-family reference
- Mobile-first presentation, with desktop support

This repository is being initialized for the first playable website prototype.

> This is a fictional story archive. Content and character details may evolve during development.
